Teil I

Die Grundlagen

Wie CSS funktioniert, wie man Elemente auswählt, Farben setzt, Text stylt und das Box Model versteht.

01 Was ist CSS?

CSS (Cascading Style Sheets) definiert das Aussehen von HTML — Farben, Layouts, Abstände, Animationen. HTML sagt was, CSS sagt wie es aussieht.

Links · Einbindung
Externes CSS

<link rel="stylesheet" href="style.css"> — der Standardweg.

Internes CSS

<style>-Block im <head>.

Inline-Style

style="color: red;" — nur Notfall.

style.css
/* Selektor { Eigenschaft: Wert; } */

h1 {
  color: #264de4;
  font-size: 2.5rem;
  font-family: sans-serif;
}

p {
  color: #333;
  line-height: 1.6;
  max-width: 60ch;
}

.highlight {
  background: yellow;
  padding: 2px 6px;
}
Rechts · Cascade
Kaskade

Inline > ID > Klasse > Element. Bei gleicher Spezifität: die spätere Regel gewinnt.

Vererbung

Manche Properties (z. B. color, font-*) werden an Kinder vererbt.

02 Selektoren Grundlagen

Selektoren bestimmen, welche Elemente gestylt werden. Die drei Grundarten: Element, Klasse, ID.

Links · Typen
Element

h1 — trifft alle <h1>-Tags.

.klasse

Trifft alles mit class="klasse". Kann mehrfach vorkommen.

#id

Einzigartig pro Seite. Höhere Spezifität — sparsam nutzen.

Kombination

p.intro = Paragraph mit Klasse intro.

selektoren.css
/* Element */
p { margin-bottom: 1rem; }

/* Klasse */
.card {
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 1rem;
}

/* ID */
#hero { background: #264de4; }

/* Kombination */
a.external { color: blue; }

/* Universalselektor */
* { box-sizing: border-box; }

/* Gruppierung */
h1, h2, h3 { font-family: serif; }
Rechts · Spezifität
Merken

ID (1-0-0) > Klasse (0-1-0) > Element (0-0-1). Inline = gewinnt immer (ausser !important).

Tipp

Nutze Klassen statt IDs für Styling — flexibler, niedrigere Spezifität.

03 Farben & Einheiten

CSS kennt viele Farb-Formate und relative Einheiten. Modern: oklch() für wahrnehmungsgleiche Farben.

Links · Formate
Hex

#ff6600 oder kurz #f60. Mit Alpha: #ff660080.

rgb / rgba

rgb(255 102 0 / 50%) — moderne Syntax ohne Kommas.

hsl

Farbton (0–360°), Sättigung, Helligkeit. Intuitiver.

oklch

Perceptually uniform. Der neue Standard für 2026.

farben.css
.box {
  /* Verschiedene Farb-Formate */
  color: #264de4;
  color: rgb(38 77 228);
  color: hsl(225 80% 52%);
  color: oklch(50% 0.2 265);

  /* Mit Transparenz */
  background: rgb(38 77 228 / 20%);

  /* Einheiten */
  font-size: 1rem;      /* relativ zu root */
  padding: 1.5em;       /* relativ zum Element */
  width: 80vw;          /* 80% der Viewport-Breite */
  max-width: 60ch;      /* 60 Zeichen breit */
  gap: clamp(1rem, 3vw, 3rem);
}
Rechts · Tipp
rem vs em

rem = relativ zu html (Standard 16px). em = relativ zum Elternelement. Für Font-Size: rem. Für Padding: em.

clamp()

clamp(min, ideal, max) — fluid zwischen min und max. Perfekt für responsive Typo.

ch

Breite des "0"-Zeichens. Ideal für Lesebreite.

04 Text & Typografie

Schriftart, Grösse, Zeilenabstand, Ausrichtung, Dekoration — alles, was Text lesbar und schön macht.

Links · Properties
font-family

Schrift-Stack mit Fallbacks. Web-Fonts via @font-face oder Google Fonts.

font-size

In rem oder clamp() für fluid.

line-height

Zeilenabstand. 1.5–1.7 für Fliesstext.

text-wrap: balance

Gleichmässige Zeilenverteilung für Headlines. Neu!

typo.css
body {
  font-family: 'Inter', system-ui, sans-serif;
  font-size: clamp(1rem, 1vw + 0.75rem, 1.25rem);
  line-height: 1.65;
  color: #1a1a1a;
}

h1 {
  font-size: clamp(2rem, 5vw, 4rem);
  font-weight: 800;
  letter-spacing: -0.03em;
  text-wrap: balance;
}

a {
  color: #264de4;
  text-decoration: underline;
  text-underline-offset: 3px;
}

.truncate {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
Rechts · Tipp
system-ui

Nutzt die System-Schrift — schnell, kein Download nötig.

text-wrap: pretty

Vermeidet Waisenwörter am Ende. Browser-Support wächst.

@font-face

Eigene Schriften laden — WOFF2-Format ist optimal.

05 Box Model

Jedes Element ist eine Box: Content → Padding → Border → Margin. Mit box-sizing: border-box wird's intuitiv.

Links · Schichten
content

Der Inhalt — Text, Bild, etc.

padding

Innenabstand zwischen Content und Border.

border

Rahmen um das Element.

margin

Aussenabstand zum nächsten Element.

border-box

width schliesst Padding + Border mit ein. Immer setzen!

box.css
/* Reset: border-box für alle */
*, *::before, *::after {
  box-sizing: border-box;
}

.card {
  width: 300px;
  padding: 24px;
  border: 2px solid #ddd;
  margin: 16px;
  /* Gesamtbreite: 300px (border-box) */
}

/* Margin Shorthand */
.box {
  margin: 10px;           /* alle 4 */
  margin: 10px 20px;      /* oben/unten links/rechts */
  margin: 10px 20px 30px 40px; /* o r u l */
}

/* Zentrieren: margin auto */
.container {
  max-width: 1200px;
  margin-inline: auto;
}
Rechts · Achtung
Margin Collapse

Vertikale Margins benachbarter Elemente überlappen sich. Nur der grössere zählt.

margin-inline: auto

Zentriert horizontal — die moderne Variante von margin: 0 auto.

06 Display

display bestimmt, wie ein Element sich verhält: block, inline, inline-block, flex, grid, none.

Links · Werte
block

Eigene Zeile, volle Breite.

inline

Im Textfluss. Width/Height werden ignoriert.

inline-block

Im Fluss, aber Width/Height funktionieren.

none

Element verschwindet komplett — kein Platz.

flex / grid

Layout-Modi — eigene Kapitel folgen.

display.css
.tag {
  display: inline-block;
  padding: 4px 12px;
  background: #264de4;
  color: white;
  border-radius: 99px;
}

.hidden { display: none; }

/* Visually hidden (Accessibility) */
.sr-only {
  position: absolute;
  width: 1px; height: 1px;
  overflow: hidden;
  clip-path: inset(50%);
}
Rechts · Notiz
none vs hidden

display: none = weg. visibility: hidden = unsichtbar, nimmt aber Platz ein.

sr-only

Visuell versteckt, aber Screenreader lesen es vor.

07 Backgrounds & Gradients

Hintergrundfarben, Bilder, Gradienten — und wie man sie kombiniert.

Links · Properties
background

Shorthand für color, image, position, size, repeat.

linear-gradient

Farbverlauf in eine Richtung.

radial-gradient

Kreisförmiger Verlauf.

bg.css
.hero {
  background: linear-gradient(135deg, #264de4, #5a8dee);
  color: white;
}

.overlay {
  background:
    linear-gradient(rgba(0,0,0,.5), rgba(0,0,0,.3)),
    url('bg.jpg') center / cover no-repeat;
}

.mesh {
  background:
    radial-gradient(at 20% 30%, #264de4 0%, transparent 50%),
    radial-gradient(at 80% 70%, #e8a64a 0%, transparent 50%);
}
Rechts · Tipp
cover vs contain

cover = füllt, schneidet ab. contain = zeigt alles, evtl. Lücken.

Mehrere Backgrounds

Mit Komma getrennt — der erste liegt oben.

08 Borders & Border-Radius

Rahmen, abgerundete Ecken und Schatten — die visuellen Details, die eine Card zur Card machen.

Links · Properties
border

Shorthand: width style color.

border-radius

Runde Ecken. 50% = Kreis (bei quadrat. Element).

box-shadow

Schatten: x y blur spread color.

outline

Wie border, aber ausserhalb des Box Models. Nutze es für Fokus!

borders.css
.card {
  border: 1px solid #e0e0e0;
  border-radius: 12px;
  box-shadow: 0 4px 12px rgb(0 0 0 / 10%);
}

.avatar {
  width: 80px; height: 80px;
  border-radius: 50%;
  border: 3px solid #264de4;
}

.btn:focus-visible {
  outline: 3px solid #264de4;
  outline-offset: 2px;
}
Rechts · Tipp
focus-visible

Zeigt Outline nur bei Keyboard-Navigation — nicht bei Mausklick.

border vs outline

Border verschiebt Layout. Outline nicht.

09 Pseudo-Klassen & -Elemente

Pseudo-Klassen (:hover, :first-child) treffen Elemente in bestimmten Zuständen. Pseudo-Elemente (::before, ::after) erzeugen virtuelle Kinder.

Links · Überblick
:hover / :focus / :active

Interaktions-Zustände.

:first-child / :last-child / :nth-child()

Position in der Elternliste.

::before / ::after

Erzeugen ein Element vor/nach dem Inhalt. Brauchen content.

::placeholder

Styled den Placeholder-Text eines Inputs.

pseudo.css
a:hover  { color: #e8a64a; }
a:focus-visible { outline: 2px solid; }

li:nth-child(odd) {
  background: #f5f5f5;
}

li:first-child { font-weight: bold; }

.badge::before {
  content: '★ ';
  color: gold;
}

.divider::after {
  content: '';
  display: block;
  height: 1px;
  background: #ddd;
  margin-top: 1rem;
}

input::placeholder {
  color: #999;
  font-style: italic;
}
Rechts · Notiz
content

Pseudo-Elemente brauchen immer content — auch wenn es '' ist.

::selection

Styled den markierten (selektierten) Text.

Teil II

Layout & Dynamik

Flexbox, Grid, Positioning, Animationen, Responsive Design, CSS Variables und fortgeschrittene Selektoren.

10 Flexbox

Flexbox ist ein 1-dimensionales Layout-System — entweder Zeile oder Spalte. Perfekt für Navigation, Card-Reihen, Zentrieren.

Links · Konzept
Container

display: flex macht das Element zum Flex-Container.

Hauptachse

flex-direction: row (Standard) oder column.

justify-content

Verteilt Kinder auf der Hauptachse.

align-items

Positioniert Kinder auf der Querachse.

gap

Abstand zwischen Flex-Kindern.

flex.css
/* Navigation */
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

/* Zentrieren (vertikal + horizontal) */
.center {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

/* Card-Reihe mit Wrapping */
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 24px;
}
.cards > * {
  flex: 1 1 300px;  /* grow shrink basis */
}

/* Footer immer unten */
.page {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
.page > main { flex: 1; }
Rechts · Tipp
flex: 1

Shorthand für flex-grow: 1; flex-shrink: 1; flex-basis: 0. Element füllt verfügbaren Platz.

order

Ändert die visuelle Reihenfolge ohne HTML-Änderung.

align-self

Überschreibt align-items für ein einzelnes Kind.

11 CSS Grid

Grid ist ein 2-dimensionales Layout-System — Zeilen und Spalten gleichzeitig. Perfekt für Seitenlayouts, Dashboards, Galerien.

Links · Konzept
grid-template-columns

Definiert Spalten. repeat(3, 1fr) = 3 gleiche Spalten.

fr

Fraction — teilt den Restplatz proportional auf.

grid-template-areas

Benannte Bereiche — visuell intuitiv.

auto-fit / auto-fill

Responsive ohne Media Queries!

grid.css
/* Basis-Grid */
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

/* Responsive Grid (keine Media Query!) */
.auto-grid {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(280px, 1fr));
  gap: 24px;
}

/* Benannte Areas */
.layout {
  display: grid;
  grid-template-areas:
    "header  header"
    "sidebar main  "
    "footer  footer";
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;
}
.layout > header  { grid-area: header; }
.layout > aside   { grid-area: sidebar; }
.layout > main    { grid-area: main; }
.layout > footer  { grid-area: footer; }
Rechts · Tipp
auto-fit vs auto-fill

auto-fit streckt Elemente. auto-fill lässt leere Spalten.

place-items: center

Shorthand für justify-items + align-items. Zentriert in der Zelle.

span

grid-column: span 2 — Element erstreckt sich über 2 Spalten.

12 Positioning

position nimmt Elemente aus dem normalen Fluss heraus — relative, absolute, fixed, sticky.

Links · Werte
relative

Verschiebt relativ zur Normalposition. Erstellt einen Positionierungs-Kontext.

absolute

Relativ zum nächsten position: relative-Vorfahren.

fixed

Relativ zum Viewport — scrollt nicht mit.

sticky

Klebt fest, sobald die Scroll-Position erreicht ist.

position.css
/* Badge oben rechts */
.card { position: relative; }
.card .badge {
  position: absolute;
  top: -8px;
  right: -8px;
  background: red;
  color: white;
  border-radius: 50%;
  width: 24px; height: 24px;
}

/* Sticky Header */
.header {
  position: sticky;
  top: 0;
  z-index: 100;
  backdrop-filter: blur(12px);
}

/* Vollbild-Overlay */
.overlay {
  position: fixed;
  inset: 0;  /* top/right/bottom/left: 0 */
  background: rgb(0 0 0 / 50%);
}
Rechts · Merken
inset

Shorthand für top, right, bottom, left.

sticky braucht top

Ohne top: 0 klebt nichts.

backdrop-filter

Glasmorphismus-Effekt — unscharfer Hintergrund hinter dem Element.

13 Transitions & Animations

transition animiert Property-Änderungen sanft. @keyframes erzeugt komplexe, mehrstufige Animationen.

Links · Konzept
transition

Shorthand: property duration timing delay.

@keyframes

Definiert Animations-Schritte (from/to oder Prozent).

animation

Verknüpft ein Element mit @keyframes.

will-change

Hinweis für den Browser — GPU-Beschleunigung.

animation.css
/* Transition */
.btn {
  background: #264de4;
  color: white;
  transition: background 200ms ease, transform 200ms ease;
}
.btn:hover {
  background: #1a3ab5;
  transform: translateY(-2px);
}

/* Keyframe-Animation */
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}

.card {
  animation: fadeIn 400ms ease-out both;
}

/* Spinner */
@keyframes spin {
  to { transform: rotate(360deg); }
}
.spinner {
  animation: spin 1s linear infinite;
}
Rechts · Performance
GPU-freundlich

Nur transform und opacity animieren — alles andere triggert Layout/Paint.

prefers-reduced-motion

Animationen abschalten für User, die das wollen — Media Query nutzen.

both

animation-fill-mode: both hält Start- und End-Zustand.

14 Responsive Design

Media Queries passen das Layout an die Bildschirmgrösse an. Mobile-First: erst das Handy stylen, dann grössere Screens.

Links · Strategie
Mobile-First

Basis-CSS = Handy. @media (min-width: ...) für grössere Screens.

Breakpoints

Gängig: 640px, 768px, 1024px, 1280px.

Container Queries

Moderner Ansatz — Layout reagiert auf die Container-Breite statt auf den Viewport (siehe Kap. 18).

responsive.css
/* Mobile-First: Basis = 1 Spalte */
.grid {
  display: grid;
  gap: 1rem;
}

/* Ab 768px: 2 Spalten */
@media (min-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Ab 1024px: 3 Spalten */
@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

/* Dark Mode */
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #1a1a1a;
    --text: #f0f0f0;
  }
}

/* Reduzierte Animationen */
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; }
}
Rechts · Tipp
min-width (mobile-first)

min-width = "ab dieser Breite". Desktop-first nutzt max-width.

prefers-*

prefers-color-scheme, prefers-reduced-motion, prefers-contrast — User-Präferenzen respektieren.

15 Custom Properties (CSS Variables)

Variablen in CSS — definiere Werte einmal, nutze sie überall. Laufzeit-dynamisch (anders als Sass-Variablen).

Links · Konzept
Definition

--name: wert auf beliebigem Element (meist :root).

Nutzung

var(--name) oder var(--name, fallback).

Scoping

Variables sind vererbbar — du kannst sie auf Kinder-Elemente überschreiben.

variables.css
:root {
  --primary: #264de4;
  --radius: 8px;
  --shadow: 0 4px 12px rgb(0 0 0 / 10%);
  --spacing: 1.5rem;
}

.btn {
  background: var(--primary);
  border-radius: var(--radius);
  padding: var(--spacing);
}

/* Theme-Wechsel per Klasse */
.dark {
  --primary: #5a8dee;
  --bg: #1a1a1a;
}

/* Per JavaScript ändern */
// document.documentElement.style
//   .setProperty('--primary', '#e44d26');
Rechts · Tipp
Fallback

var(--color, blue) — falls die Variable nicht gesetzt ist.

JS-Zugriff

Lese und schreibe CSS-Variablen per setProperty() / getPropertyValue().

Calc

calc(var(--spacing) * 2) — rechne mit Variables.

16 Selektoren Fortgeschritten

:has(), :is(), :where(), :not(), Kombinatoren und Attribut-Selektoren — die volle Macht der CSS-Selektoren.

Links · Selektoren
:has()

Eltern-Selektor! .card:has(img) = Cards mit Bild.

:is() / :where()

Gruppierung. :where hat Spezifität 0.

:not()

Negation: p:not(.intro) = alle p ausser .intro.

Kombinatoren

> (Kind), + (nächster Sibling), ~ (alle Siblings).

selektoren-adv.css
/* :has() — Eltern-Selektor */
.card:has(img) {
  grid-column: span 2;
}

form:has(:invalid) {
  border-color: red;
}

/* :is() — kompakte Gruppierung */
:is(h1, h2, h3) {
  font-family: serif;
  line-height: 1.2;
}

/* :where() — Spezifität 0 */
:where(.article, .post) p {
  line-height: 1.7;
}

/* Attribut-Selektor */
a[href^="https"] { /* beginnt mit */ }
a[href$=".pdf"]  { /* endet mit */ }
img[src*="hero"] { /* enthält */ }

/* Sibling-Kombinator */
h2 + p { font-size: 1.1rem; }
Rechts · Tipp
:has() = Game Changer

Endlich Eltern stylen basierend auf Kindern — seit 2023 in allen Browsern.

:is vs :where

:is übernimmt die höchste Spezifität seiner Argumente. :where = 0.

17 Overflow, z-index & Stacking

Was passiert, wenn Inhalt überfliesst? Und wie bestimmt z-index, welches Element oben liegt?

Links · Konzepte
overflow

visible (Standard), hidden, scroll, auto, clip.

z-index

Funktioniert nur mit position (nicht static). Höher = oben.

Stacking Context

Wird durch position + z-index, opacity < 1, transform, etc. erzeugt.

stacking.css
/* Overflow */
.scroll-box {
  max-height: 300px;
  overflow-y: auto;
}

.clip {
  overflow: clip;  /* wie hidden, ohne Scroll-Möglichkeit */
}

/* z-index Strategie */
:root {
  --z-dropdown: 100;
  --z-sticky: 200;
  --z-modal: 300;
  --z-toast: 400;
}

.modal {
  position: fixed;
  inset: 0;
  z-index: var(--z-modal);
}

/* isolation: neuen Stacking Context erzwingen */
.card { isolation: isolate; }
Rechts · Merken
z-index Chaos

Definiere z-index-Stufen als Variables. Nie z-index: 9999.

isolation: isolate

Erzwingt neuen Stacking Context, ohne Position/Opacity zu ändern.

overflow: clip

Wie hidden, aber verhindert auch programmatisches Scrollen.

Moderne Features

18 Container Queries

Statt auf den Viewport reagiert dein Layout auf die Breite des Containers. Perfekt für wiederverwendbare Komponenten.

Links · Konzept
container-type

inline-size = reagiert auf Breite. size = Breite + Höhe.

container-name

Optional — ermöglicht gezielte Abfragen.

@container

Wie @media, aber für den Container.

container.css
.card-wrapper {
  container-type: inline-size;
  container-name: card;
}

.card {
  display: flex;
  flex-direction: column;
}

@container card (min-width: 400px) {
  .card {
    flex-direction: row;
    gap: 1rem;
  }
  .card img {
    width: 200px;
  }
}

/* Container-Query Units */
.card h2 {
  font-size: clamp(1rem, 3cqi, 2rem);
  /* cqi = 1% der Container inline-size */
}
Rechts · Tipp
cqi / cqb

cqi = container query inline (Breite). cqb = block (Höhe). Wie vw/vh aber für Container.

Warum?

Media Queries = globale Breite. Container Queries = lokale Breite. Komponenten werden dadurch wirklich wiederverwendbar.

19 CSS Nesting

Endlich nativ: Regeln innerhalb von Regeln verschachteln — wie in Sass, aber ohne Präprozessor.

Links · Syntax
Verschachteln

Kind-Selektoren direkt im Eltern-Block.

&

Referenziert den Eltern-Selektor — für Pseudo-Klassen, Modifikatoren.

@media in Nesting

Media Queries direkt im Selektor-Block — kein Kontextwechsel.

nesting.css
.card {
  padding: 1.5rem;
  border: 1px solid #ddd;

  h2 {
    font-size: 1.5rem;
    margin-bottom: 0.5rem;
  }

  p {
    color: #666;
  }

  /* & für Pseudo-Klassen */
  &:hover {
    box-shadow: 0 4px 16px rgb(0 0 0 / 15%);
  }

  /* & für Modifikatoren */
  &.featured {
    border-color: #264de4;
  }

  /* Media Query direkt hier */
  @media (min-width: 768px) {
    padding: 2rem;
  }
}
Rechts · Tipp
Nicht zu tief!

Maximal 3 Ebenen verschachteln — sonst wird der Output zu spezifisch.

Browser-Support

Seit 2023 in allen modernen Browsern. Kein Sass mehr nötig für Nesting.

20 Logical Properties

Statt left/right nutzt du inline-start/inline-end — funktioniert automatisch für RTL-Sprachen (Arabisch, Hebräisch).

Links · Mapping
Block

Vertikale Achse: margin-block, padding-block, border-block.

Inline

Horizontale Achse: margin-inline, padding-inline, border-inline.

Shorthands

margin-block: 1rem 2rem = margin-top: 1rem; margin-bottom: 2rem.

logical.css
.container {
  /* Alt: margin: 0 auto; */
  margin-inline: auto;
  max-inline-size: 1200px;  /* = max-width */
  padding-inline: 1rem;
}

.sidebar {
  /* Alt: border-right: 1px solid #ddd; */
  border-inline-end: 1px solid #ddd;
  padding-inline-end: 2rem;
}

.text {
  /* Alt: text-align: left; */
  text-align: start;
}

.box {
  inset-block-start: 0;   /* = top: 0 */
  inline-size: 100%;      /* = width: 100% */
  block-size: 50vh;       /* = height: 50vh */
}
Rechts · Warum?
Internationalisierung

In RTL (z. B. Arabisch) wird inline-start automatisch zu right.

Moderne Praxis

Nutze margin-inline, padding-block etc. als Default — auch wenn du nur LTR baust.

21 Scroll-Snap & Scroll Animations

Karusselle ohne JavaScript mit scroll-snap, und CSS-Animationen, die an die Scroll-Position gekoppelt sind.

Links · Features
scroll-snap-type

x mandatory oder y proximity. Auf dem Container.

scroll-snap-align

start, center, end. Auf den Kindern.

animation-timeline

scroll() oder view() — Animation an Scroll-Position binden.

scroll.css
/* Scroll-Snap Karussell */
.carousel {
  display: flex;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
  gap: 1rem;
  scrollbar-width: none;
}
.carousel > * {
  scroll-snap-align: center;
  flex: 0 0 80%;
}

/* Scroll-driven Animation */
@keyframes reveal {
  from { opacity: 0; transform: translateY(40px); }
  to   { opacity: 1; transform: translateY(0); }
}

.card {
  animation: reveal linear both;
  animation-timeline: view();
  animation-range: entry 0% entry 100%;
}
Rechts · Tipp
view()

Animiert, wenn das Element in den Viewport scrollt. Kein Intersection Observer nötig.

scroll()

Bindet an die Scroll-Position des Containers — z. B. Fortschrittsbalken.

animation-range

Definiert, in welchem Teil des Scroll-Bereichs die Animation läuft.

22 Subgrid

Ein Grid-Kind übernimmt die Tracks des Eltern-Grids — endlich konsistente Ausrichtung über verschachtelte Ebenen.

Links · Problem
Ohne Subgrid

Verschachtelte Grids haben eigene Spalten — Inhalte sind nicht ausgerichtet.

Mit Subgrid

Kind nutzt grid-template-columns: subgrid — übernimmt die Spalten des Eltern-Grids.

subgrid.css
.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 1rem;
}

.card {
  grid-column: span 2;
  display: grid;
  /* Kind nutzt Eltern-Tracks! */
  grid-template-columns: subgrid;
  grid-template-rows: subgrid;
  grid-row: span 3;
}
Rechts · Use Case
Card-Layouts

Überschriften, Bilder und Buttons auf der gleichen Baseline-Höhe — über alle Cards.

Support

Seit 2023 in allen Browsern.

23 @layer & Cascade Layers

Cascade Layers geben dir Kontrolle über die Reihenfolge der Kaskade — unabhängig von Spezifität und Quellcode-Reihenfolge.

Links · Konzept
@layer

Definiert einen Layer. Spätere Layer gewinnen über frühere.

Reihenfolge

Declare die Reihenfolge oben, fülle die Layer später.

Unlayered CSS

CSS ohne @layer gewinnt über alle Layer.

layers.css
/* Reihenfolge festlegen */
@layer reset, base, components, utilities;

@layer reset {
  *, *::before, *::after {
    margin: 0;
    box-sizing: border-box;
  }
}

@layer base {
  body { font-family: system-ui; }
  a { color: #264de4; }
}

@layer components {
  .btn {
    padding: 0.75rem 1.5rem;
    background: #264de4;
    color: white;
  }
}

@layer utilities {
  .text-center { text-align: center; }
  .mt-4 { margin-top: 1rem; }
}
Rechts · Warum?
3rd-Party CSS

@import url('lib.css') layer(lib) — importiertes CSS in einen Layer packen = leicht zu überschreiben.

Kein !important

Layers machen !important überflüssig — saubere Kaskaden-Kontrolle.

24 View Transitions

Sanfte Übergänge zwischen Seitenwechseln — nativ im Browser, ohne JavaScript-Frameworks.

Links · API
@view-transition

navigation: auto aktiviert Transitions für MPA-Navigation.

view-transition-name

Verbindet ein Element über zwei Seiten hinweg — wird animiert.

Pseudo-Elemente

::view-transition-old und ::view-transition-new für Custom-Animationen.

view-transition.css
/* MPA View Transitions aktivieren */
@view-transition {
  navigation: auto;
}

/* Element über Seiten hinweg animieren */
.hero-img {
  view-transition-name: hero;
}

/* Custom Animation */
::view-transition-old(hero) {
  animation: fadeOut 200ms ease;
}
::view-transition-new(hero) {
  animation: fadeIn 300ms ease;
}

/* SPA: per JavaScript */
// document.startViewTransition(() => {
//   updateDOM();
// });
Rechts · Tipp
MPA vs SPA

MPA: @view-transition im CSS reicht. SPA: document.startViewTransition() per JS.

Einzigartige Namen

Jedes view-transition-name muss einzigartig pro Seite sein.

Reduced Motion

Respektiere prefers-reduced-motion — deaktiviere Transitions für empfindliche User.

25 Color Functions (oklch, color-mix)

Moderne Farbfunktionen: oklch() für wahrnehmungsgleiche Farben, color-mix() zum Mischen, light-dark() für Theme-Support.

Links · Funktionen
oklch()

Lightness (0–100%), Chroma (Sättigung), Hue (Farbwinkel). Perceptually uniform.

color-mix()

Mischt zwei Farben in einem Farbraum.

light-dark()

Gibt je nach color-scheme einen anderen Wert zurück.

Relative Color

Farbe basierend auf einer anderen ableiten.

colors.css
:root {
  color-scheme: light dark;

  /* oklch: L C H */
  --primary: oklch(55% 0.25 265);
  --primary-light: oklch(75% 0.15 265);

  /* color-mix: Farben mischen */
  --hover:
    color-mix(in oklch, var(--primary), black 20%);

  /* light-dark: Theme-abhängig */
  --bg: light-dark(#ffffff, #1a1a1a);
  --text: light-dark(#1a1a1a, #f0f0f0);
}

/* Relative Color Syntax */
.btn:hover {
  background: oklch(from var(--primary) calc(l - 0.1) c h);
}

/* Palette generieren mit oklch */
:root {
  --blue-100: oklch(95% 0.05 265);
  --blue-300: oklch(75% 0.15 265);
  --blue-500: oklch(55% 0.25 265);
  --blue-700: oklch(35% 0.20 265);
  --blue-900: oklch(20% 0.10 265);
}
Rechts · Warum oklch?
Gleichmässig

In hsl sehen Farben mit gleichem L-Wert unterschiedlich hell aus. oklch fixiert das.

P3 Gamut

oklch kann Farben ausserhalb des sRGB-Gamuts darstellen — lebhaftere Farben auf modernen Displays.

light-dark()

Braucht color-scheme auf dem Element. Einfachste Methode für Dark Mode.
